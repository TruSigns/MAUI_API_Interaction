# SDC_440

This repository contains my .NET MAUI projects and related API work.

## Projects

### MAUI_First_App

A basic .NET MAUI application used to practice UI controls such as labels, entry fields, buttons, grids, and event handlers.

### MAUI_Basic_Login

A login application that allows a user to enter a username and password, validates the credentials, displays a login result, and clears the form with a Cancel button.

### MauiPageNavigation

A two page .NET MAUI application that demonstrates page navigation and passing data between pages. The user can enter a message on the main page, send it to the second page, and navigate back to the main page.

### MAUI_Add_Subtract

A two page calculator application that accepts two values, performs addition or subtraction, validates missing input, and displays the result on a second page.

### RSVP_App

A multi page RSVP application that supports user registration, SQLite based login validation, guest access, event creation, event lists, event details, RSVP submission, and logout functionality.

### MAUIWebAPI

An ASP.NET Core Web API project that provides RESTful GET and POST endpoints for person data and uses SQLite for data storage.

### MAUI_Data_Access

A .NET MAUI application that demonstrates local SQLite storage through a Data Access Layer. The app validates user input, stores person records, retrieves saved records, and displays them in a CollectionView.

### MAUI_Item_Storage

A .NET MAUI data entry application that stores item information in SQLite, validates required fields, retrieves saved items, and displays the stored records in the user interface.
