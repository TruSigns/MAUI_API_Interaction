# SDC_440

This repository contains my .NET MAUI projects.

## Projects

### MAUI_First_App

A basic .NET MAUI application used to practice UI controls such as labels, entry fields, buttons, grids, and event handlers.

### MAUI_Basic_Login

A login application that allows a user to enter a username and password, validates the credentials, displays a login result, and clears the form with a Cancel button.

### MauiPageNavigation

A two page .NET MAUI application that demonstrates page navigation and passing data between pages. The user can enter a message on the main page, send it to the second page, and navigate back to the main page.
